About the Project

Technology-driven video analytics prototype

IBVAP stands for Intelligent Border Video Analytics Platform. The project explores the use of computer vision and AI techniques to process video footage, detect people and identify events within a sample monitoring region. It also explores cryptographic hashing for checking the integrity of generated evidence files.

Core Features

Key capabilities explored in our prototype

🤖

AI Person Detection

Uses a pretrained YOLO model to identify people in uploaded video footage.

🎥

Video Processing

Uses OpenCV to process video frames and generate annotated output.

📍

Sample Zone Monitoring

Demonstrates a configurable rectangular sample region and event alerts.

🔐

Evidence Integrity

Uses SHA-256 hashing to calculate file fingerprints for integrity checks.

Project Scope & Limitations

This website presents the project overview. The current prototype uses pretrained YOLO person detection, OpenCV video processing, a sample rectangular monitoring region and local SHA-256 hashing. Advanced RGB-thermal fusion, custom model training, digital signatures and blockchain integration are not represented as completed features in this version.
